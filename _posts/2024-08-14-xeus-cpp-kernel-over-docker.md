As a data science I am so used to use Jupyter notebook as
a deliverity tool for explanatory data or even executable
program in production.

I have allways liked it's simplicity, the integration with text in html and
markdown and the interaction provided by this tool to run sections of code. One
of the keys points is that it is extreamly easy to use notebooks to explain not
thecnical people procedures of executions.

In my mind I though Jupyter notebook could only work using interpreted
languages, but I found that it is not true, seeking a little bit on the
internet I end up to a post which explain the integration of Jupyter notebooks
for teaching. Navigating a little bit I discovered that community have created
different kernels that would work with different programming languages such as,
C++, Haskell, Scala and much more.
